# HYP_PROTOCOL — Deploy Guide

84-дневная RPG-кампания по гипертрофии. Здесь — инструкция как опубликовать игру в интернете и установить её на iPhone как PWA.

Весь процесс — 15-20 минут. Никакого кода писать не надо.

---

## Что в этой папке

- `index.html` — главный файл, точка входа
- `game.js` — вся игра (~80 KB)
- `manifest.json` — PWA-манифест
- `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-icon.png` — иконки для главного экрана iPhone
- `README.md` — это файл

---

## Шаг 1. Создаёшь репозиторий на GitHub

1. Заходи на https://github.com и логинься.
2. Жми зелёную кнопку **New** в верхнем левом углу (или https://github.com/new напрямую).
3. Заполняешь форму:
   - **Repository name:** `hyp-protocol` (или любое другое, без пробелов)
   - **Public** или **Private** — пофигу, для деплоя работают оба
   - НЕ ставь галочки "Add a README", "Add .gitignore", "Choose a license" — мы свой README уже подготовили
4. Жми **Create repository** внизу.

После создания GitHub покажет тебе пустой репозиторий с инструкциями. Игнорируй их, переходи к шагу 2.

## Шаг 2. Заливаешь файлы

Самый простой способ — через веб-интерфейс GitHub без терминала:

1. На странице репозитория жми ссылку **uploading an existing file** (она прямо в инструкциях посередине), либо ползи в **Add file → Upload files**.
2. Перетащи в окно браузера **все файлы** из этой папки (`index.html`, `game.js`, `manifest.json`, `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-icon.png`, `README.md`). Перетащи именно файлы, не папку.
3. Внизу в **Commit changes** напиши что-нибудь типа `initial deploy` и жми зелёную кнопку **Commit changes**.

После загрузки увидишь все 8 файлов в репозитории.

## Шаг 3. Подключаешь Vercel

1. Заходи на https://vercel.com и логинься через **Continue with GitHub** (Vercel попросит разрешения, дай).
2. После логина увидишь дашборд. Жми **Add New... → Project** в верхнем правом углу.
3. Vercel покажет твои GitHub-репозитории. Найди `hyp-protocol`, жми **Import** напротив него.
4. Откроется форма "Configure Project". Ничего не меняй — все дефолты подойдут (Framework: Other, Root Directory: ./, Build Command: пусто, Output Directory: пусто). Просто жми **Deploy** внизу.
5. Жди 30-60 секунд. Vercel соберёт и задеплоит. Когда увидишь "Congratulations" с конфетти — жми **Continue to Dashboard** или просто на превью.
6. Скопируй URL — он будет вида `https://hyp-protocol.vercel.app` или `https://hyp-protocol-xxx.vercel.app`.

Открой этот URL в браузере на компьютере чтобы проверить — должен загрузиться онбординг `HYP_PROTOCOL`.

## Шаг 4. Устанавливаешь на iPhone

1. Открой Safari на iPhone (именно Safari, не Chrome — PWA-установка через "На экран Домой" работает только в Safari).
2. Перейди по своему Vercel URL.
3. Дождись пока загрузится онбординг.
4. Тапни иконку **Поделиться** (квадратик со стрелочкой вверх в нижней панели Safari).
5. Прокрути вниз, найди **На экран «Домой»** / **Add to Home Screen**.
6. Имя по умолчанию будет "HYP" — оставляй или меняй на любое. Тапни **Добавить**.
7. На главном экране появится иконка `HYP`. Тапай — игра откроется в полноэкранном режиме без браузерных рамок, как нативное приложение.

Готово. Это твой ЗБТ-билд.

## Как обновлять игру

Когда я пришлю новую версию `game.js` (или другие правки):

1. Заходишь в репозиторий на GitHub.
2. Кликаешь на старый файл (например `game.js`).
3. Справа сверху иконка карандаша — **Edit this file** (или просто заменяешь файл через Upload files).
4. Вставляешь новое содержимое или перезаливаешь файл.
5. Внизу **Commit changes**.
6. Vercel **автоматически** увидит изменение и за ~30 секунд передеплоит сайт.
7. На iPhone открой приложение — у тебя обновлённая версия. Никаких re-installation.

## Локальное хранение данных

Все твои данные (профиль, миссии, фото, статы) хранятся **только в Safari/PWA на твоём iPhone** через `localStorage`. Они никуда не отправляются, ни на какой сервер.

Это означает:
- Никаких аккаунтов, паролей, регистрации
- Если очистишь данные сайта в настройках Safari — потеряешь прогресс
- Если переустановишь PWA — потеряешь прогресс
- Не синхронизируется между устройствами

Для ЗБТ это нормально. Когда дойдём до Mac-версии через Claude Code — переедем на iCloud-синхронизацию или нативную iOS базу данных.

## Если что-то пошло не так

**Сайт открывается, но падает с ошибкой.**
Открой консоль на компьютере (F12 → Console), посмотри ошибку, пришли мне скриншот.

**На iPhone иконка добавилась, но открывается в Safari, а не в полноэкранном режиме.**
Проверь что на странице `manifest.json` корректно подгружается. На компьютере открой `https://твой-url.vercel.app/manifest.json` — должен показать JSON. Если 404 — возможно файл не загрузился в репозиторий.

**Хочу всё стереть и начать кампанию заново.**
В игре: AGENT → пролистай вниз → `dev · reset campaign` → подтверди. Страница перезагрузится с онбордингом.
Запасной вариант: на iPhone в Настройки → Safari → Дополнения → Данные сайтов → найти твой Vercel-URL → Удалить.

**Игра тормозит или фризится.**
Скорее всего слишком много фото в `localStorage`. Лимит ~5MB. Будем оптимизировать.
