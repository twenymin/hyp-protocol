# ГИПЕР_ПРОТОКОЛ v8.1 — Фикс сохранения

Критический фикс системы сохранения. Это **обновление поверх v7**.

## Что произошло в v7 (баг)

В v7 я изменил архитектуру: статы становятся объектом только **после** калибровки Дня 1. До этого `state.stats === null`. А функция чтения сохранения проверяла:

```js
if (parsed.startDate && parsed.stats && parsed.daysData) return parsed;
```

Если `stats === null` — проверка возвращала `false`, игра считала что сохранения нет, и стартовала онбординг с нуля. **Прогресс при этом всё это время лежал в localStorage**, просто игнорировался.

То же самое в v6 могло происходить если данные сохранились в кривом виде — старая проверка молча отбрасывала их.

## Что фикшено в v8.1

1. **Корректное чтение сохранения.** Новая функция `isValidState()` правильно валидирует структуру и **разрешает** `stats === null` (это нормально между онбордингом и завершением калибровки).

2. **Резервный ключ.** Каждое сохранение пишет копию в `BACKUP_KEY`. Если основной ключ повредился — игра автоматически читает бэкап.

3. **Видимое автосохранение.** Снизу экрана теперь выезжает уведомление:
   - Зелёное `✓ СОХРАНЕНО · 14:23` после каждого успешного сохранения (1.8 сек)
   - Красное `⚠ ХРАНИЛИЩЕ ПЕРЕПОЛНЕНО` или `⚠ НЕ УДАЛОСЬ СОХРАНИТЬ` при ошибке (6 сек)

4. **Метка времени сохранения.** В каждом save теперь есть `_savedAt` — поможет показывать «последнее сохранение HH:MM» в будущем.

5. **Day rollover при возвращении в фокус.** Раньше день пересчитывался только раз в минуту. Теперь — ещё и при `visibilitychange` и `focus` событиях. Открыл приложение через сутки → день моментально перескочит на правильный.

6. **Диагностический лог.** Последние 20 событий сохранения (включая ошибки) пишутся в `SAVE_LOG_KEY`. Можно посмотреть в DevTools → Application → Local Storage → `hyp_protocol_v1_log` если что-то пошло не так.

## Что в очереди на v8.2 (следующий коммит)

— Полноценный экран **НАСТРОЙКИ** с секциями:
  - 💾 Сохранение (кнопка «сохранить сейчас», экспорт .json через Web Share API на iPhone, импорт)
  - 📊 Хранилище (сколько занято из 5 МБ, сколько фото)
  - 📅 День игры (текущий день, дата старта, кнопка ручной синхронизации)
  - ⚠ Сброс
— Возможность скачать save-файл в iCloud Drive / Файлы → застраховаться от случайной потери данных PWA

## Как обновить

1. Зайди в свой GitHub-репозиторий.
2. Add file → Upload files → перетащи **только** `game.js`, `index.html`, `manifest.json`, `README.md`. PNG-иконки **не трогай** — они не менялись.
3. Commit changes.
4. Vercel автоматически передеплоит за ~30 секунд.
5. На iPhone: закрой приложение свайпом вверх → открой заново.

## Если у тебя был прогресс в v6/v7 и он "пропал"

Скорее всего он жив, просто игра его не читала. Открой свой Vercel-URL **на компьютере в Chrome**, F12 → Application → Local Storage → найди ключ `hyp_protocol_v1_state` или `hyp_protocol_v1_backup`. Если там есть JSON — он есть! После обновления на v8.1 игра сможет его прочитать.

Если решишь начать заново — на экране ГЕРОЙ внизу кнопка **СБРОСИТЬ КАМПАНИЮ**.

## Если уведомление о сохранении не появляется

Это значит что-то вообще не так с localStorage в Safari iOS (например ITP его заблокировал). Дай мне знать, тогда в v8.2 добавлю IndexedDB как альтернативу.
